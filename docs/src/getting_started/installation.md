# Installation

## Installing Webrogue CLI

Webrogue CLI utility is a swiss-knife that we will use frequently.
It is distributed using GitHub Releases [there](https://github.com/webrogue-runtime/webrogue/releases/latest). See files prefixed with `webrogue-cli-`.

You can download it using following links:
- Windows:
[x64](https://github.com/webrogue-runtime/webrogue/releases/latest/download/webrogue-cli-windows-x86_64.zip);
[ARM64](https://github.com/webrogue-runtime/webrogue/releases/latest/download/webrogue-cli-windows-aarch64.zip).
- macOS:
[Apple Silicon](https://github.com/webrogue-runtime/webrogue/releases/latest/download/webrogue-cli-macos-arm64.tar.gz);
[Intel](https://github.com/webrogue-runtime/webrogue/releases/latest/download/webrogue-cli-macos-x86_64.tar.gz).
- Linux:
[glibc x86_64](https://github.com/webrogue-runtime/webrogue/releases/latest/download/webrogue-cli-linux-glibc-x86_64.tar.gz);
[glibc AArch64](https://github.com/webrogue-runtime/webrogue/releases/latest/download/webrogue-cli-linux-glibc-aarch64.tar.gz);
[musl x86_64](https://github.com/webrogue-runtime/webrogue/releases/latest/download/webrogue-cli-linux-musl-x86_64.tar.gz);
[musl AArch64](https://github.com/webrogue-runtime/webrogue/releases/latest/download/webrogue-cli-linux-musl-aarch64.tar.gz).
